# marketing-automation

## Etsy Shop Sync

Real (non-placeholder) Etsy shop data sync — listings, orders/revenue, and
reviews via the Etsy Open API v3, runnable weekly — plus a weekly report
that ranks niches/listings by revenue and flags pricing opportunities so
you know where to focus. See [`etsy_sync/README.md`](etsy_sync/README.md)
for setup and usage.
## Bet Scanner

Scans Polymarket against sportsbook consensus odds and alerts your phone
(ntfy, Make.com webhook, or email) when a moneyline is underpriced by 4+
points, with a capped stake suggestion. Alerts only, it never places bets. See
[`bet_scanner/README.md`](bet_scanner/README.md) for setup and usage.
