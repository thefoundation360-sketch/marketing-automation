# marketing-automation

## Etsy Shop Sync

Real (non-placeholder) Etsy shop data sync — listings, orders/revenue, and
reviews via the Etsy Open API v3, runnable weekly — plus a weekly report
that ranks niches/listings by revenue and flags pricing opportunities so
you know where to focus. See [`etsy_sync/README.md`](etsy_sync/README.md)
for setup and usage.
